# Exemplos reais

Aqui ficam exemplos **reais** do método aplicados a casos de uso concluídos, para estudo. Os playbooks e templates em `method/` não contêm dados de nenhum projeto específico; os nomes, portas e números do CeliLac vivem **somente** aqui e em `project-profile.md`.

| Exemplo | Situação |
|---|---|
| UC12 — Cadastrar Produto (CeliLac) | Será adicionado na Etapa 6 (piloto), com o `state.yaml` reconciliado, o relatório de cada fase e as ADRs de cobertura |

> Ao copiar o método para o seu projeto, **não copie esta pasta**: ela descreve o CeliLac, não o seu caso de uso.
